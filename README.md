# Bank Anime Power — واجهة تجريبية

موقع صفحات ثابتة باللغة العربية لعرض صفحات أنمي باور والمنتجات والعروض. المنتجات والعروض التي يضيفها الزائر تُحفظ في `localStorage` على جهازه فقط؛ لا يوجد خادم لتسجيل الحسابات أو مزامنة البيانات.

## ما تم إصلاحه

- أزيل تسجيل الدخول الوهمي، الذي كان يحفظ كلمات المرور كنص واضح في المتصفح. إنشاء الحساب وتسجيل الدخول غير مفعّلين إلى أن يُضاف خادم آمن.
- أزيلت حقول البطاقة ورقمها وتاريخها وCVV، وتوقّف الموقع عن ادعاء نجاح دفع غير حقيقي. لا يوجد مزوّد دفع أو اتصال بالخزينة في المشروع.
- يزيل `security-cleanup.js` مفاتيح `users` و`purchases` القديمة من تخزين المتصفح عند فتح أي صفحة محدثة؛ لا يحذف بيانات المنتجات والعروض.
- عُدّل عرض أسماء المنتجات والعروض إلى عناصر نصية آمنة بدل إدخالها كـ HTML، وحُصرت الصور على ملفات محلية مسماة فقط.
- أُصلح إعداد Docker ليقدّم صفحات HTML الثابتة مباشرةً عبر Nginx بدل محاولة بناء تطبيق React غير موجود.
- لم يُضمّن سجل Git القديم؛ كان يشير إلى مستودع لحساب آخر. أنشئ سجل Git جديدًا عند رفع هذه النسخة إلى مستودعك.

## التشغيل محليًا

افتح `index.html` في متصفح حديث، أو شغّل خادمًا محليًا داخل المجلد:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## التشغيل باستخدام Docker

```bash
docker build -t bank-anime-power .
docker run --rm -p 8080:8080 bank-anime-power
```

ثم افتح `http://localhost:8080`.

> هذه نسخة عرض فقط، وليست نظام حسابات أو متجرًا ينفّذ عمليات شراء. لا تُدخل فيها كلمات مرور أو بيانات بطاقات. إضافة تسجيل حقيقي أو دفع تتطلب خادمًا ومزوّد دفع معتمدًا.
